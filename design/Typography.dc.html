Nastaliq runs 15–20% larger with roughly double the leading, and it has no usable bold — emphasis comes from size and colour, never synthetic weight. The scale is chosen per run because one sentence contains both scripts; choosing by locale breaks on exactly the mixed line that matters most.
The citation island where bilingual legal UI usually breaks
Without isolation
قتلِ عمد 302–304 .s PPC کے تحت
Brackets, commas and the range dash take direction from context. Inside a right-to-left paragraph they resolve right-to-left and migrate to the wrong end. A citation whose parts reorder is a different citation.
First-strong isolates
قتلِ عمد s. 302–304 PPC کے تحت
Every foreign run wrapped in U+2068 … U+2069. Neutrals now resolve inside the isolate and the citation stays one indivisible island. Isolates, not the deprecated embeddings — those leak across adjacent runs.
Digits stay Western
Section numbers, article numbers, years in citations and case numbers use 0–9 in both scripts, always. A localised section number is a wrong citation. Only quantities in running prose may take Eastern forms.
Three language axes
UI language, content language and input script move independently. A user reads Urdu chrome around English statutory text and types talaq on a Latin keyboard — all three at once, routinely.

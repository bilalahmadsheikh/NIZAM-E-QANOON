§0Mandate

The corpus is evidence, not a folder of PDFs

The five downloaded archives are a strong baseline: 4,710 official-code PDFs, 1,857 MB on disk and about 243 MB after text extraction. They are not yet a legally dependable corpus. A dependable corpus also knows where each file came from, when it was fetched, what publication it represents, what it changes, where every provision appears on the source page, and whether the result passed objective gates.

Non-negotiable rule

PDF extraction is performed once for a new content hash. Search, RAG and document generation read structured rows from Document 03. They never open or parse a PDF. A file is reprocessed only when its bytes change, the parser version changes, or a curator explicitly requests repair.

§1Authority
model

Keep the publication, consolidation and cross-check separate

Several official sites may carry the same Act, but they do not play the same evidential role. The pipeline records each observation and resolves them by authority and date; it never silently overwrites one official copy with another.

RankSource roleUseConflict policy
A1Official Gazette publicationEnacted text, notification number, publication date, commencement notices, rules and SROsPreserve as the publication event. Escalate a byte/text conflict; never auto-merge
A2Official legislature recordAct number, passage, assent, Gazette date and newly enacted PDFCross-check A1; useful as the fastest new-law signal
A3Government law-code consolidationConvenient current text, amendments incorporated, subject and chronology indexesServe only with its consolidation date; verify changes against A1/A2
A4Court or regulator publicationJudgments, orders, rules, regulations, circulars and sector instrumentsAuthoritative for that issuing body; connect to the enabling law and later appellate treatment
A5Secondary discovery sourceFinding a missing citation or documentNever publish from it. Use it only to locate an A1–A4 copy

A source is “official” because it is controlled by the issuing government, legislature, court or regulator—not merely because its domain looks governmental. Every adapter is manually approved once with organization, jurisdiction, TLS status, publication role and terms recorded in the source registry.

§3Acquisition

Every fetch is reproducible and non-destructive

3.1Fetcher contract

  • Identify the client and obey published robots and rate constraints; one host-specific token bucket, jitter and exponential backoff.
  • Use If-None-Match and If-Modified-Since where supported. A 304 records freshness without downloading or parsing.
  • Accept a PDF only when HTTP succeeds, MIME sniffing and %PDF- agree, size is plausible and the full-stream hash completes. Preserve HTML source snapshots as well as document bytes.
  • Write to a temporary object, verify, then atomically promote to raw/{source_id}/{sha256}. Never overwrite a prior source blob.
  • Record missing links and parse errors as first-class observations. A disappearing official file triggers review; it does not delete the published corpus.

§4Extract
& recover

Use the cheapest faithful lane for each page

OCR is a fallback, not the default. Many legal PDFs already contain usable text, while some mix born-digital pages with scanned schedules or Gazette stamps. Routing is page-level so one bad page does not force OCR across an entire Act.

LaneDetectionProcessingAcceptance
E1Official HTMLDOM blocks retained with heading/list/table semanticsHeading sequence and text checksum stable after boilerplate removal
E2Born-digital PDFLayout-aware glyph/text extraction with coordinates≥95% printable characters; no missing-page or repeated-glyph anomaly
E3Mixed PDFE2 on good pages; render and OCR only failed pagesEvery page assigned a lane; page order preserved
E4Scanned PDF300 DPI render, deskew, denoise, script-aware OCR; English and Urdu/Sindhi models selected per regionLegal-token checks plus human review below threshold
E5Image/table scheduleRegion detection; cell grid and row/column recovery; source image retainedTotals, headers and row counts reconcile or route to curation

4.1Never destroy the page evidence

The canonical output is not a plain text file. Each block carries {page, bbox, reading_order, script, extractor, confidence}; every provision stores page anchors back to the immutable source. Hyphen repair, ligature expansion and whitespace normalization create derived text while the exact extracted form remains available for audit.

No translation in ingestion. English, Urdu and Sindhi publications are separate official expressions linked by instrument identity. Generated translation belongs to the explanation layer and must never replace statutory wording.

§5Legal
structure

Parse the law, not arbitrary token windows

5.1Numbering grammar

Parse headings and labels with a jurisdiction-aware grammar: section 3, 3-A, 3AA, (1), (a), (i), provisos, explanations, illustrations and schedules. Indentation and coordinates are evidence, not truth; numbering, punctuation, font changes and table-of-contents reconciliation vote together.

5.2Chunking for RAG

  • Chunk only after the legal tree exists. Default boundary is a complete subsection or a group of adjacent clauses under one subsection.
  • Repeat compact context—instrument title, jurisdiction, section heading and defined-term scope—in chunk metadata, not by altering quoted text.
  • Never split a proviso, exception, explanation or definition from the rule it qualifies. Oversized schedules use row-aware chunks.
  • Each chunk retains ordered character spans into one provision version. Regeneration may change chunk IDs without changing citations or bookmarks.

7.1Change classification

  • Mirror change: URL or filename changed but hash did not—link a new observation, do no extraction.
  • Presentation change: hash changed but normalized legal text did not—retain the new expression and page anchors; do not create a legal version.
  • Consolidation change: legal text changed on a code portal—diff at provision level and require an amending authority before publication.
  • New enactment or notification: create the publication event, resolve affected provisions and publish atomically only after gates pass.
  • Parser correction: transaction-time correction, not a claim that the law changed on that date.

8.1Curation is an auditable patch

The curator sees the rendered source page and parsed tree together. Allowed operations are typed—split/merge block, relabel node, correct text with source span, resolve identity, accept/reject relationship. Each correction stores before, after, operator, timestamp, reason and page evidence. Re-running the same parser applies approved patches after extraction, so manual work survives rebuilds.

Sampling is risk-based: 100% of OCR documents, status-changing relationships, commencement/invalidation candidates and parser regressions; a stratified sample of clean born-digital documents by source and era.

9.1Idempotent job graph

discover(source_cursor)
  → fetch(observation)                 # no-op for 304 or known hash
  → extract(sha256, extractor_version) # cached by exact inputs
  → segment(extraction, grammar_version)
  → enrich(tree, resolver_version)
  → gate(candidate, gate_version)
  → curate?(failure package)
  → publish(candidate_set)             # single L1 → L2 boundary

Every stage is content-addressed and retryable. Queues provide work delivery, not truth; the durable stage record decides whether work has already succeeded. A dead-letter item names its source, stage, attempt count and stable error code.

10.1Definition of done for Document 02

  • A complete rebuild from immutable blobs and versioned code produces the same published corpus hash.
  • No user request reads or parses a PDF; production serves only published L2 records.
  • Every displayed quotation resolves to official URL, content hash, page and source span.
  • Every source has a currency and completeness status visible to operations and expressible to users.
  • A failed or partial ingest cannot change the live corpus.
  • Unknown commencement or judicial status is represented as unknown, never guessed from silence.
